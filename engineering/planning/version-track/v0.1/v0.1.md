### Iteration 1 — The domain

- [x] Repo created from the domain template; core pin `10.0.111-beta`; transitive security pin on `Microsoft.AspNetCore.SignalR.StackExchangeRedis` 10.0.15.
- [x] Contract (`Ai.Abstractions`): runner, prompts in `rewrite` or `versioned` mode with labels, model prices, the inference log, evals with sets, runs, scores, ratings, a report, export and import; `IEvalSubjectSource` for products.
- [x] `Ai.Providers`: `anthropic` (official `Anthropic` 13.8.0), `openai` (any OpenAI-compatible host, `Microsoft.Extensions.AI.OpenAI` 10.8.3 over `OpenAI` 2.12.0), `ollama`; named by `Ai:Providers:{name}`; one attempt per call with usage, latency, classified errors; effort through `ChatOptions.Reasoning`; Anthropic's system prompt cached.
- [x] `Ai.Module`: migrations `002-ai-layer` (10 tables, the `ai_eval_report_rows` view) and `003-seed-prices` (Claude Haiku, Sonnet and Opus 5.5, `gpt-6-luna`, `gpt-6.1-terra`, read 2026-11-10); the runner (route, retries, fallback, schema check, cache, micro-USD cost, OpenTelemetry GenAI tags); evals scored by fields with severe-miss rules.
- [x] `service/Ai.Api` on `ServiceHost`: `ai` operator verbs for use cases, prompts, labels, prices, runs, the inference log and evals (`eval run` takes a model × version matrix; `eval report --format json|md|csv`); `UserSecretsId` for provider keys on the local bench.
- [x] Testing: `ScriptedAiModelCaller`, `PromptsBrokerConformance`; the Greetings sample removed from every tier, the dev check reads `/api/system/status`.
- [x] `fe-ai`: contract mirrors, cost and latency formatters, `EvalReportView`.
- [x] Tests: unit 64, providers 106, integration 31, conformance 15, migrations 16, E2E 28; frontend lint, test, build, package check.
